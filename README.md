# 成电深研校园网自动重连（Windows）

这是一个用于 **成电深研校园网** 的 Windows PowerShell 脚本，适配下述特定 `ac_portal` 认证页面。它会在当前用户登录 Windows 期间每分钟检查一次网络；掉线时尝试登录，且距上次成功认证满 12 小时后主动重新认证。计划任务通过 VBScript 隐藏启动，不会每分钟弹出终端。

> **适用范围**：代码里的门户地址是 `http://2.2.2.3/ac_portal/...`，登录接口是 `http://2.2.2.3/ac_portal/login.php`。其他学校的门户、表单字段或加密方式可能不同，不能直接保证可用。请先确认学校允许自动认证，并遵守其网络使用规定。

## 使用方法

1. 在 Windows 10/11 上下载此仓库，并解压到一个固定位置。
2. 连接校园网，在该目录双击 `一键安装.cmd`。安装程序会在本机询问账号和密码，并将运行脚本安装到 `%LOCALAPPDATA%\CampusNetAutoLogin`。不要把账号密码写进仓库。
3. 双击 `查看状态.cmd` 检查最近一次巡检和认证结果。需要立即重新认证时，双击 `立即重连.cmd`。
4. 不再使用时双击 `一键卸载.cmd`；默认会删除计划任务、本机加密凭据、状态和日志。

安装会创建名为 `CampusNet Auto Login` 的 Windows 计划任务，以当前登录用户的权限运行。电脑必须开机且该用户已登录；锁屏期间可以运行，睡眠、关机或退出登录期间不能运行。唤醒或重新登录后，任务会继续检查。

## 状态和故障排查

运行数据保存在 `%LOCALAPPDATA%\CampusNetAutoLogin`：

- `last-run.json`：最近一次执行回执。检查 `completed`、`outcome` 和 `exitCode`，不要只看计划任务的返回码。
- `campusnet.log`：认证过程。`AUTH_ACCEPTED` 表示门户接受了登录，`authenticated` 表示随后也验证了外网连通。
- `launcher.log`：隐藏启动器的执行情况。
- `state.json`：认证时间与退避状态，不含明文密码。
- `credential.xml`：本机凭据。**绝不要上传或分享此文件**，即使它看起来是加密的。

如果显示 `portal-mismatch`，说明认证页面与脚本预期不符；`portal-rejected` 表示门户拒绝凭据，自动提交会暂停，需检查账号密码；`portal-unreachable` 通常是门户不可达或请求失败。安装程序在更新已有版本时会备份旧脚本和任务定义（不复制凭据）。

## 安全提醒

此门户本身使用 **HTTP**，不是 HTTPS。脚本遵循该门户原有的登录协议，传输链路不能提供 TLS 的保密或防篡改保护；不要把脚本中使用的混淆算法当作传输加密。脚本在提交前会检查页面特征，并禁止自动跳转，但这不能替代 HTTPS。凭据通过 Windows DPAPI 保存在本机、仅供同一 Windows 用户读取；日志不记录明文密码或服务器响应正文。请勿将安装目录、日志、状态文件或备份提交到 GitHub。
